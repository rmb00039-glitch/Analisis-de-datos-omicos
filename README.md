#### **This repositories verse about the two projects done during "Análisis de datos ómicos" Lecture, encompassed in the Bioinformatics and Biostatistics Master taught by the University of Barcelona and the Open University of Cantalunya**
##### The first file (PEC 1) covers how to use the `SummarizedExperiment` package, as well as the pre-processing and preliminary analysis of such data, using multivariate analysis techniques such as PCA or clustering. 
##### The second focuses on the analysis of RNA-Seq of virological data data using `SummarizedExperiment` and `edgeR`.
##### The third deals with mutation detection via variant calling in exomes, using the Galaxy platform.
